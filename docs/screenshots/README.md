# Скриншоты

Эта директория содержит реальные скриншоты UI tajik-fire, сделанные через
Playwright на запущенном приложении. Все файлы — `.png` с retina-плотностью
(device_scale_factor=2), базовое разрешение 1440×900 если не указано иное.

## Как сделаны скриншоты

Скрипт в `/scripts/shoot.py` (родительский репозиторий) запускает FastAPI,
логинится как `demo / Demo1234`, делает один сабмит, чтобы в ленте появились
данные, и обходит 16 страниц, делая скриншот каждой.

## Обновление скриншотов

```bash
cd ..  # в корень репо
pip install playwright
python3 -m playwright install chromium
python3 scripts/shoot.py
```

Скрипт сам поднимет FastAPI на `127.0.0.1:8777`, обойдёт все страницы и
перезапишет `.png` в этой директории.
